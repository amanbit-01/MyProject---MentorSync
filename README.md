# MyProject---MentorSync# TrackMyProject

TrackMyProject is a web-based project progress tracking system designed for students and mentors.

It helps students submit their weekly project progress and allows mentors to review and monitor their work through separate dashboards.

## About the Project

During project development, students need to regularly show their progress to mentors. TrackMyProject provides a simple platform where students can submit their weekly work online and mentors can review their progress.

## Features

### Student
- Student registration and login
- Student dashboard
- Submit weekly project progress
- Add project description
- Upload screenshot or report
- Add live project link

### Mentor
- Mentor registration and login
- Mentor dashboard
- View assigned students
- View student project details
- Check weekly project progress
- Review project work

## Technologies Used

- HTML
- CSS
- JavaScript
- Python (Future Backend)
- SQL (Future Database)

## Project Pages

- Home Page
- Login Page
- Registration Page
- Student Dashboard
- Mentor Dashboard
- Student Details Page

## How It Works

1. Student or Mentor registers on the website.
2. User selects their role and logs in.
3. Student submits weekly project updates.
4. Mentor views the student list.
5. Mentor opens student details and reviews the project progress.

## Current Status

The current version is a front-end prototype developed using HTML, CSS and JavaScript.

Backend authentication and permanent data storage can be added in the future using Python and SQL.

## Purpose

The main purpose of TrackMyProject is to make student project monitoring simple, organized and efficient.
